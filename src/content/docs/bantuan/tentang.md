JavaRouters dibangun di atas **[New API](https://github.com/QuantumNous/new-api)** karya **QuantumNous**, yang dirilis dengan lisensi [GNU AGPL v3](https://www.gnu.org/licenses/agpl-3.0.html). New API sendiri dikembangkan dari [One API](https://github.com/songquanpeng/one-api) (lisensi MIT).

Sesuai lisensi AGPL v3, kode sumber JavaRouters beserta perubahannya tersedia untuk umum di [github.com/BIGBANG-69/javarouters](https://github.com/BIGBANG-69/javarouters).

Dokumentasi ini dibuat dengan [Starlight](https://starlight.astro.build).
