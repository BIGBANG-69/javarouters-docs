```http
POST https://javarouters.talentadigitalkudus.id/v1/chat/completions
```

Endpoint utama JavaRouters, mengikuti format [Chat Completions OpenAI](https://platform.openai.com/docs/api-reference/chat). Endpoint ini bisa dipakai untuk **semua model yang dijual**, termasuk Claude, Gemini, dan DeepSeek, bukan hanya GPT.

## Header

| Header | Nilai |
|---|---|
| `Authorization` | `Bearer sk-...` |
| `Content-Type` | `application/json` |

## Body request

| Parameter | Tipe | Wajib | Keterangan |
|---|---|---|---|
| `model` | string | Ya | Nama model dari [daftar model](/docs/api/daftar-model/), misalnya `claude-sonnet-4.6`. |
| `messages` | array | Ya | Riwayat percakapan. Lihat [Format messages](#format-messages). |
| `stream` | boolean | Tidak | `true` untuk menerima jawaban bertahap. Lihat [Streaming](/docs/panduan/streaming/). |
| `stream_options` | object | Tidak | `{"include_usage": true}` meminta jumlah token di chunk terakhir saat streaming. |
| `max_tokens` | integer | Tidak | Batas jumlah token jawaban. |
| `temperature` | number | Tidak | Variasi jawaban. Nilai kecil membuat jawaban lebih konsisten. |
| `top_p` | number | Tidak | Alternatif `temperature` (nucleus sampling). |
| `stop` | string / array | Tidak | Teks yang menghentikan jawaban. |
| `tools` | array | Tidak | Daftar fungsi yang boleh dipanggil model. Lihat [Tool calling](/docs/panduan/tool-calling/). |
| `tool_choice` | string / object | Tidak | `auto`, `none`, `required`, atau fungsi tertentu. |
| `response_format` | object | Tidak | Misalnya `{"type": "json_object"}` untuk meminta jawaban JSON. |
| `user` | string | Tidak | ID pengguna akhir di aplikasimu, untuk pelacakan. |

Parameter lain dari format OpenAI diteruskan ke model. **Dukungan setiap parameter tergantung model**; parameter yang tidak didukung bisa diabaikan atau menghasilkan error `400`.

### Format messages

```json
[
  { "role": "system", "content": "Kamu asisten yang menjawab dalam bahasa Indonesia." },
  { "role": "user", "content": "Apa itu API gateway?" },
  { "role": "assistant", "content": "API gateway adalah ..." },
  { "role": "user", "content": "Beri contoh pemakaiannya." }
]
```

| Role | Fungsi |
|---|---|
| `system` | Instruksi umum untuk model. |
| `user` | Pesan dari pengguna. |
| `assistant` | Jawaban model sebelumnya (untuk menyimpan konteks percakapan). |
| `tool` | Hasil pemanggilan fungsi. Lihat [Tool calling](/docs/panduan/tool-calling/). |

<TabItem label="Python">

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://javarouters.talentadigitalkudus.id/v1",
    api_key=os.environ["JAVAROUTERS_API_KEY"],
)

response = client.chat.completions.create(
    model="claude-sonnet-4.6",
    max_tokens=512,
    messages=[
        {"role": "system", "content": "Jawab dalam bahasa Indonesia."},
        {"role": "user", "content": "Apa itu API gateway?"},
    ],
)
print(response.choices[0].message.content)
print(response.usage)
```

## Respons

```json
{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "created": 1762560000,
  "model": "claude-sonnet-4.6",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "API gateway adalah ..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 24,
    "completion_tokens": 180,
    "total_tokens": 204
  }
}
```

| Field | Keterangan |
|---|---|
| `choices[0].message.content` | Teks jawaban. |
| `choices[0].message.tool_calls` | Ada jika model memanggil fungsi. |
| `choices[0].finish_reason` | `stop` (selesai), `length` (terpotong `max_tokens`), atau `tool_calls`. |
| `usage` | Jumlah token. Biaya request dihitung dari angka ini. |

Angka di contoh di atas hanya ilustrasi.

## Streaming

Dengan `"stream": true`, jawaban dikirim bertahap sebagai Server-Sent Events. Format chunk dan contoh membacanya ada di [Streaming](/docs/panduan/streaming/).
